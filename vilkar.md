# Bruksvilkår for Økonomi – privat bankimport

Verktøyet er laget for min egen, private og ikke-kommersielle bruk. Det brukes til å lese saldo og transaksjoner fra egne kontoer som jeg har gitt tilgang til. Verktøyet kan ikke gjennomføre betalinger eller overføringer.

Tilgang til kontodata forutsetter at jeg godkjenner kontodeling gjennom Enable Banking og banken. Jeg kan når som helst trekke samtykket tilbake på [samtykkesiden til Enable Banking](https://enablebanking.com/data-sharing-consents/).

For informasjon om hvordan verktøyet behandler kontodata, se [personvernerklæringen](personvern.md).
